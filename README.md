# Sistema de Gestión de Biblioteca

Este proyecto es un sistema simple de gestión de biblioteca desarrollado en Java, utilizando estructuras de datos lineales.

## Funcionalidades

- Registrar libros
- Registrar usuarios
- Buscar libros por ID
- Prestar libros
- Devolver libros
- Visualizar libros, usuarios y préstamos

## Tecnologías

- Java
- ArrayList (estructuras de datos lineales)

## Estructura del proyecto

- model → entidades (Libro, Usuario, Prestamo)
- estructura → manejo de estructuras (ListaLibros, ListaUsuarios)
- service → lógica del sistema (BibliotecaService)
- ui → interfaz por consola (Menu)
- Main → punto de entrada del programa
